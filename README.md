# Twitch TV для Hisense (VIDAA) — 58A6K и другие

Неофициальное приложение Twitch для телевизоров Hisense на VIDAA: эфиры, категории, каналы, записи, клипы, чат, избранное, поиск. Управление с пульта.

Работает прямо с GitHub Pages: ничего собирать не нужно, телевизор просто открывает ссылку.

## 1. Включить GitHub Pages (один раз)

1. В репозитории откройте **Settings → Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** выберите ветку с приложением (`main` или `claude/peaceful-cori-qupxj3`), папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт заработает по адресу:
   `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/`

## 2. Установить на телевизор

1. На ТВ откройте браузер и введите в адресной строке `hisense://debug`.
2. Заполните форму:

| Поле | Что вписать |
|---|---|
| **App Name** | `Twitch` |
| **Thumbnail** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/thumbnail.png` |
| **IconSmall** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/icon-small.png` |
| **IconLarge** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/icon-large.png` |
| **App Url** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/` |
| **Resolution** | `1080` |

3. Нажмите **INSTALL**. Приложение появится в **My Apps**: фиолетовая плитка с логотипом Twitch, как у Netflix и YouTube. Её можно перенести в верхний ряд.

> Если раньше уже ставили приложение с таким же именем, сначала удалите старое в списке Installed Apps или дайте другое имя.

## Пульт

| Кнопка | Действие |
|---|---|
| Стрелки, OK | навигация, выбор |
| Назад | назад; на главной — меню, потом выход |
| CH+ / CH− | следующий / предыдущий эфир из того же ряда |
| ▶❚❚ / Стоп | пауза / закрыть плеер |
| ⏩ / ⏪, ← → на полосе | перемотка записей (с ускорением при удержании) |
| 🔴 красная | качество видео |
| 🟢 зелёная | чат |
| 🟡 жёлтая | добавить в избранное / убрать |
| 🔵 синяя | перезагрузить поток |

## Почему не тормозит (в отличие от SmartTwitchTV)

- Поток только в **H.264 (avc1)**: его ТВ декодирует аппаратно.
- hls.js настроен под ТВ: умеренный буфер (не переполняет память), осторожное повышение и быстрое понижение качества, понижение качества при пропуске кадров.
- **Сторож от зависаний**: если картинка застыла, плеер сам перепрыгивает дыру в буфере, догоняет эфир, лечит декодер, а в крайнем случае получает новый токен и перезапускает поток.
- Повторы при сбоях сети, автоматический новый токен при его истечении.
- Чат рисуется пачками раз в 250 мс, а превью грузятся лениво, поэтому интерфейс не подлагивает.

Если эфир всё же подтормаживает, в **Настройках** поставьте «Задержка эфира: Стабильная» и/или «Качество: 720p60».

## Структура

```
index.html          — разметка
css/app.css         — оформление (цвета и стиль Twitch)
js/twitch.js        — API Twitch (GQL, токены, HLS)
js/player.js        — плеер и восстановление после сбоев
js/chat.js          — чат (IRC по WebSocket, эмоуты Twitch/7TV/BTTV/FFZ)
js/nav.js           — навигация с пульта
js/ui.js, pages.js  — интерфейс и страницы
js/app.js           — ядро
icons/              — иконки для установки
tools/make-icons.js — генерация иконок (node + playwright)
```

Twitch — товарный знак Twitch Interactive, Inc. Это неофициальный клиент для личного использования.
