# Twitch TV для Hisense (VIDAA) — 58A6K и другие

Неофициальное приложение Twitch для телевизоров на **VIDAA**: эфиры, категории, каналы, записи, клипы, чат со значками и эмоутами Twitch, прогнозы и голосования, избранное, поиск. Управление с пульта. 27 языков интерфейса — как на twitch.tv (язык берётся из настроек ТВ, его можно сменить в Настройках).

- **Разработчик:** [github.com/PainFrenemy2](https://github.com/PainFrenemy2)
- **Издатель:** Null/Code

## Какие телевизоры поддерживаются

Приложение работает на **всех телевизорах с системой VIDAA** (VIDAA OS / VIDAA U):

- **Hisense** — модели с VIDAA (например, 58A6K, A6, A7, E7, U7, U8 и др.);
- **Toshiba**, **Sharp**, **Loewe**, **Daewoo** и другие марки, у которых в меню написано VIDAA.

Как понять, что у вас VIDAA: на главном экране ТВ есть раздел **My Apps** / **Мои приложения**, а в **Настройки → Система → О телевизоре** указана VIDAA. Устанавливается одинаково на любой такой ТВ — см. раздел 2.

Работает прямо с GitHub Pages: ничего собирать не нужно, телевизор просто открывает ссылку.

## 1. Включить GitHub Pages (один раз)

1. В репозитории откройте **Settings → Pages**.
2. **Source:** `Deploy from a branch`.
3. **Branch:** выберите ветку с приложением (`main` или `claude/peaceful-cori-qupxj3`), папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт заработает по адресу:
   `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/`

## 2. Установить на телевизор (Hisense и любой другой ТВ на VIDAA)

1. На ТВ откройте встроенный браузер и введите в адресной строке `hisense://debug` (адрес одинаковый для всех ТВ на VIDAA, в том числе Toshiba и Sharp).
2. Заполните форму:

| Поле | Что вписать |
|---|---|
| **App Name** | `Twitch` |
| **Thumbnail** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/tile-thumb.png` |
| **IconSmall** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/tile-small.png` |
| **IconLarge** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/icons/tile-large.png` |
| **App Url** | `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/` |
| **Resolution** | `1080` |

3. Нажмите **INSTALL**. Приложение появится в **My Apps**: фиолетовая плитка с логотипом Twitch, как у Netflix и YouTube. Её можно перенести в верхний ряд.

> Если раньше уже ставили приложение с таким же именем, сначала удалите старое в списке Installed Apps или дайте другое имя.
>
> Если `hisense://debug` не открывается (на некоторых прошивках VIDAA он скрыт), просто откройте адрес приложения `https://painfrenemy2.github.io/TVAppTwitch-Hisense-/` во встроенном браузере ТВ и добавьте его в закладки — всё работает так же, кроме плитки в My Apps.

## Что умеет

- **Возвращает туда, где вы вышли**: при следующем запуске открывается та же страница или тот же эфир (можно выключить: Настройки → При запуске).
- **Не выкидывает из аккаунта**: вход хранится с резервной копией; если Twitch всё-таки отозвал вход — профиль, избранное и подписки остаются, достаточно войти снова по коду.
- **Пропуск рекламы Twitch**: во время рекламной паузы («Commercial break in progress») плеер переключается на резервный поток Twitch без рекламы (Настройки → Видео).
- **Прогнозы и голосования**: когда стример их запускает, в плеере всплывает подсказка (OK — участвовать; отключается в Настройках). Нужен вход в Twitch.
- **Значки и эмоуты Twitch** в чате берутся прямо с Twitch — новые и сезонные (Хэллоуин, Новый год и т.п.) появляются сами. Плюс эмоуты 7TV, BTTV, FFZ.
- **Параметры плеера**: качество, вид чата, таймер сна, статистика, «Пожаловаться», «Заблокировать канал», «Сообщить о проблеме».
- Все настройки — выбор из списка: OK → список вариантов справа.

## Почему не тормозит (в отличие от SmartTwitchTV)

- Поток только в **H.264 (avc1)**: его ТВ декодирует аппаратно.
- hls.js настроен под ТВ: умеренный буфер (не переполняет память), осторожное повышение и быстрое понижение качества, понижение качества при пропуске кадров.
- **Сторож от зависаний**: если картинка застыла, плеер сам перепрыгивает дыру в буфере, догоняет эфир, лечит декодер, а в крайнем случае получает новый токен и перезапускает поток.
- Повторы при сбоях сети, автоматический новый токен при его истечении.
- Чат рисуется пачками раз в 250 мс, а превью грузятся лениво, поэтому интерфейс не подлагивает.
- Ряд «Другие каналы» в плеере выезжает сдвигом слоя (transform), без пересчёта раскладки — нет микролагов.

Если эфир всё же подтормаживает, в **Настройках** поставьте «Задержка эфира: Стабильная» и/или «Качество: 720p60».

## Структура

```

css/app.css         — оформление (цвета и стиль Twitch)
js/twitch.js        — API Twitch (GQL, токены, HLS)
js/player.js        — плеер и восстановление после сбоев
js/chat.js          — чат (IRC по WebSocket, значки и эмоуты Twitch/7TV/BTTV/FFZ)
js/events.js        — прогнозы и голосования
js/i18n.js, js/i18n/ — языки интерфейса (переводы: tools/strings.tsv, tools/i18n/*.tsv → python3 tools/build-i18n.py)
js/nav.js           — навигация с пульта
js/ui.js, pages.js  — интерфейс и страницы
js/app.js           — ядро
icons/              — иконки для установки
tools/make-icons.js — генерация иконок (node + playwright)
```
